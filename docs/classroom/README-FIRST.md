# NexysVHDL 0.6.0 (Classroom Preview) — read this first

NexysVHDL lets you write VHDL for the **Digilent Nexys A7-100T** board in VS Code, then check, simulate, build and program it.

**Open the folder for your computer and follow its README:**

| Your computer | Open this folder | Read |
|---|---|---|
| Windows 10/11 PC | `Windows` | `README-WINDOWS.md` |
| Mac with Apple silicon (M1 or newer) | `macOS` | `README-MACOS.md` |

Intel Macs and Linux are not supported in this preview.

`Board_Test` is a small test project: LED0 blinks when switch SW0 is on.

You do **not** need anything else. Do not install other FPGA tools for this.
