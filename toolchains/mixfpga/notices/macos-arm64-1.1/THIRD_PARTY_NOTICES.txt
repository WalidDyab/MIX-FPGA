MIX-FPGA Toolchain 1.1 for macOS (Apple silicon): third-party notices

MIX-FPGA Toolchain is an aggregation of separate programs and data. Each part is under its own licence,
listed below; the licence texts are in the LICENSES folder next to this file, unchanged from their sources.
MIX-FPGA's own code (Apache-2.0) covers only the MIX-FPGA-authored parts (the engine scripts in engine/).

Not part of this toolchain and not redistributed by MIX-FPGA (section 3): Altera Quartus Prime Lite and the MAX 10 package,
Apple Rosetta and macOS, Ubuntu. They belong to their owners and are used under the student's own acceptance of their licences.

CHANGES MADE BY MIX-FPGA TO UPSTREAM CONTENT

MIX-FPGA patches and rebuilds no third-party program. The only changes to the official release content are:

  - Removed the VHDL-87 and VHDL-93 IEEE libraries (lib/ghdl/ieee/v87, lib/ghdl/ieee/v93 and lib/ghdl/src/ieee): they contain the IEEE 1076.3-1995 numeric_bit and numeric_std sources, which may be distributed only unchanged and not sold or distributed for profit.
  - Removed the VITAL-95 and VITAL-2000 packages (lib/ghdl/src/vital95, lib/ghdl/src/vital2000) and the UPF package (lib/ghdl/src/upf), whose licence is not established.
  - Regenerated the GHDL 2008 and 2019 IEEE library indexes (lib/ghdl/ieee/v08/ieee-obj08.cf, lib/ghdl/ieee/v19/ieee-obj19.cf) with GHDL itself, using the upstream rules of libraries/Makefile.inc without the removed packages (scripts/toolchain/ghdl-prune.mjs); the analysis timestamps of the upstream release are kept.
  - Removed the 111 openFPGALoader bridge bitstreams (share/openFPGALoader/spiOverJtag_*, bpiOverJtag_*): no provenance; MIX-FPGA programs SRAM only and never uses them.
  - Added the licence texts of the libraries compiled into the yosys executable, and Lima's own NOTICE file, which the official Lima tarball does not contain.
  - MIX-FPGA always runs GHDL with --std=08. A design that uses the removed packages gets a normal "unit not found" error.

5. OPEN QUESTIONS

L1 [resolved] IEEE 1076.3-1995 packages: 'may not be sold or distributed for profit'
    RESOLUTION: Removed in Toolchain 1.1: the VHDL-87/93 IEEE libraries (with the IEEE 1076.3-1995 numeric_bit/numeric_std packages) are no longer shipped. MIX-FPGA runs only --std=08.

L2 [resolved] VITAL and UPF packages have no licence statement in their files
    RESOLUTION: Removed in Toolchain 1.1: VITAL-95, VITAL-2000 and UPF are no longer shipped; the 2008/2019 library indexes were regenerated without them.

L3 [needs-decision] Yosys is distributed linked with GPL-3.0-or-later readline
    The yosys executable loads libreadline.8.2.dylib (GPL-3.0-or-later, shipped beside it). MIX-FPGA treats the pair as a GPLv3 combination (Yosys is ISC, which is GPL-compatible), ships the GPLv3 text and provides the complete corresponding source of both (Yosys with abc and cxxopts, readline 8.2 with patch 001 and the MacPorts recipe, the build scripts) in the source package. Counsel must confirm the combined-work position.

L4 [needs-decision] Yosys source of the exact binary, and notices of libraries compiled into it
    See yosys-program: the "-dirty" suffix is explained by the build recipe; the libraries compiled into the binary are now identified and their texts shipped. Counsel and the project owner decide whether the explanation is accepted without a reproduced build.

L5 [resolved] libusb text shipped in the payload is a 1.0.24 revision, the library is 1.0.26
    RESOLUTION: LICENSES/libusb/COPYING (LGPL-2.1) is shipped next to the 1.0.24-revision LICENSE.libusb; the 1.0.26 source is in the source package.

L6 [resolved] GHDL build recipe and GCC/GNAT runtime origin not fully recorded
    RESOLUTION: The GHDL build recipe (.github/workflows/Build-MacOS.yml, Pipeline.yml) is in the GHDL source archive: llvm-jit, macOS 15, GNAT FSF 14.2.0-1, Homebrew LLVM.

L7 [resolved] Does GHDL's GPL reach students' simulation output?
    RESOLUTION: GHDL v6.0.0 doc/licenses.rst: GRT and std.textio are GPLv2; executables produced by GHDL need the VHDL sources. MIX-FPGA runs in memory and distributes no student executables; the notices tell students.

L8 [minor] Headers without a licence statement (vpi_user.h, synth_gates.h)
    See the components vpi-header and ghdl-gpl-headers.

L9 [needs-decision] Integrity enforcement versus the right to replace LGPL/GPL libraries
    libusb, libftdi1 and libghw (LGPL) and readline (GPLv3) are separate replaceable files. The installed toolchain is read-only by default and the integrity check reports a replaced file as "changed" (Setup page, Verify); Repair restores the original only when the student chooses Repair, nothing is restored automatically and the tools keep running with replaced files (tested in Phase 5B). The notices explain how to replace a library. Counsel must confirm this satisfies the LGPL/GPL replacement rights.

L10 [resolved] openFPGALoader bridge bitstreams: provenance
    RESOLUTION: Removed in Toolchain 1.1: the 111 openFPGALoader bridge bitstreams are no longer shipped.

L11 [resolved] Lima third-party licences: collected; one MPL-2.0 module needs a source pointer
    RESOLUTION: Lima NOTICE is shipped under LICENSES/lima/; the MPL-2.0 hcl module source is in the corresponding-source package.
